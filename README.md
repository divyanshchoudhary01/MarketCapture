# MarketCapture

> Production-Grade Low-Latency Market Data Platform for US Equity Markets

MarketCapture is an open-source C++20 framework for building low-latency market data systems.

## Vision

Build a production-grade market data platform capable of:

- NASDAQ ITCH 5.0 parsing
- MoldUDP64 packet decoding
- Lock-free event processing
- Order book reconstruction
- Binary tick recording
- Deterministic replay
- Strategy APIs
- Performance benchmarking
- Future DPDK and FPGA integration
